# بوت "مُجيب" - دليل التشغيل

⚠️ **تنويه:** البوت الحين مصمم ليتكلم معه ولي الأمر **مباشرة بالخاص** (مو بقروب). أي حد يفتح محادثة خاصة مع البوت ويكتب "السلام عليكم" أو أي كلمة ترحيب، يطلعله قائمة أزرار يضغط عليها يوصل للمعلومة اللي يبيها. تقدرين تشاركين يوزر البوت (@your_bot_username) مع أولياء الأمور مباشرة بدل رابط قروب.


## الخطوة ١: الحصول على توكن البوت
1. افتحي تليجرام وابحثي عن **BotFather**
2. اكتبي له `/newbot`
3. اختاري اسم للبوت (أي اسم)، ثم username لازم ينتهي بـ `bot` مثل `parents_group_bot`
4. بيعطيك **توكن** طويل شكله كذا: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
5. احفظي هذا التوكن

## الخطوة ٢: تثبيت البرامج المطلوبة
1. نزّلي **Node.js** من الموقع الرسمي: https://nodejs.org (اختاري النسخة LTS)
2. فكّي ملف المشروع (المجلد اللي بعثته لك) في أي مكان بجهازك

## الخطوة ٣: تثبيت المكتبات
افتحي **Terminal / cmd** داخل مجلد المشروع واكتبي:
```
npm install
```

## الخطوة ٤: حطي التوكن
افتحي ملف `bot.js` وغيّري هذا السطر:
```js
const TOKEN = process.env.BOT_TOKEN || "PUT_YOUR_TOKEN_HERE";
```
استبدلي `PUT_YOUR_TOKEN_HERE` بالتوكن اللي أخذتيه من BotFather.

## الخطوة ٥: تشغيل البوت
```
npm start
```
لو شفتي رسالة "✅ البوت شغال الحين..." يعني تمام، البوت شغال.

## الخطوة ٦: إضافة البوت للقروب
1. افتحي قروب أولياء الأمور بتليجرام
2. أضيفي البوت كعضو (ابحثي عن الـ username اللي سويتيه)
3. **مهم:** روحي إعدادات القروب → Administrators → أضيفي البوت كـ Admin (عشان يقدر يشوف الرسائل ويرحب بالأعضاء الجدد)

---

## كيف أضيف سؤال جديد؟
افتحي ملف `config.js` بس، ما تحتاجين تلمسين أي ملف ثاني.

مثال لإضافة سؤال نصي جديد داخل `textAnswers`:
```js
{
  keywords: ["الاختبارات", "متى الاختبار"],
  answer: "الاختبارات تبدأ يوم الأحد القادم",
},
```

بعد أي تعديل بملف `config.js`، لازم توقفين البوت (`Ctrl + C`) وتشغلينه من جديد (`npm start`).

## تشغيل البوت مجاناً بدون جهاز شغال (Render + UptimeRobot)

### الخطوة ١: حساب GitHub
1. روحي https://github.com وسوي حساب مجاني
2. اضغطي **New repository** (فوق يمين، علامة +)
3. سميه أي اسم (مثلاً `parents-bot`)، اختاري **Private**، ثم **Create repository**
4. بالصفحة اللي تفتح، اضغطي **uploading an existing file**
5. اسحبي كل ملفات مجلد `bot` (بما فيها مجلد `schedules`) وارفعيها، ثم **Commit changes**

### الخطوة ٢: حساب Render
1. روحي https://render.com وسوي حساب مجاني (تقدرين تسجلين دخول بحساب GitHub مباشرة)
2. اضغطي **New** → **Web Service**
3. اختاري الـ repository اللي رفعتيه
4. الإعدادات:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
5. تحت **Environment Variables** أضيفي متغير:
   - Key: `BOT_TOKEN`
   - Value: التوكن حقك من BotFather
6. اضغطي **Create Web Service** وانتظري لين يخلص النشر (Deploy) — بياخذ كم دقيقة

بعد ما يخلص، بيعطيك رابط شكله: `https://parents-bot.onrender.com`

### الخطوة ٣: UptimeRobot (يخلي البوت صاحي ٢٤ ساعة)
1. روحي https://uptimerobot.com وسوي حساب مجاني
2. **Add New Monitor**
3. Monitor Type: **HTTP(s)**
4. حطي الرابط اللي طلع لك من Render
5. Monitoring Interval: **5 minutes**
6. احفظي

كذا UptimeRobot بيدق على البوت كل ٥ دقائق ويخليه صاحي دايماً — والبوت يشتغل ٢٤ ساعة مجاناً بدون ما يحتاج جهازك أبداً.

⚠️ **ملاحظة:** إذا سويتي أي تعديل بملف `config.js` بعدين، لازم ترفعينه لنفس الـ GitHub repo (استبدال الملف القديم)، و Render بيحدث البوت تلقائياً خلال دقايق.
